One word an Indonesian grandma would text about AI.

## The word

> Canggih

Indonesian for "high-tech, sophisticated" — what a grandma actually texts
when her grandchild shows her AI: warm admiration, a little baffled, and it
only really fits impressive technology. The first instinct was "Waduh", the
classic grandma gasp, but a generic gasp would fit any surprise at all, and
the judge weighs being tied to AI, robots or machines above freshness — so
the word kept the grandma voice and gained the subject.

## How it works

`main.ts` holds the word as a string constant, checks it is 1–30 characters
and a single word with no whitespace, then writes it to `/output/entry.txt`
with no trailing newline and reads the file back to confirm it is
byte-identical. It uses only absolute paths, so it runs from any working
directory.

Run it with Node 22:

```sh
node main.ts
```
